# CJPayment 用户操作手册

## 概述

CJPayment是一个企业内部支付管理系统，用于处理公司内部的充值业务。本手册将指导您如何使用系统的各项功能。

## 系统登录

### 1. 访问系统

在浏览器中输入系统地址：`https://cjpayment.company.com`

### 2. 登录步骤

1. 在登录页面输入用户名和密码
2. 点击"登录"按钮
3. 系统验证成功后，自动跳转到主页面

![登录页面](images/login.png)

### 3. 忘记密码

如果忘记密码，请联系系统管理员重置密码。

## 主界面介绍

### 导航菜单

系统主界面包含以下主要功能模块：

- **充值管理**: 创建和管理充值订单
- **财务审核**: 审核充值订单和处理退款
- **商户管理**: 管理商户信息和收款账户
- **数据报表**: 查看各类统计报表
- **系统管理**: 用户和权限管理
- **个人中心**: 修改个人信息和密码

![主界面](images/dashboard.png)

## 充值管理

### 创建充值订单

#### 1. 进入充值页面

点击左侧菜单"充值管理" → "创建充值"

#### 2. 填写充值信息

**基本信息**
- **转账类型**: 选择"公对公"或"私对私"
- **付款人名称**: 输入付款人姓名或公司名称
- **付款账号**: 输入付款银行账号或支付宝/微信账号
- **付款金额**: 输入充值金额（必须大于0）

**充值目标**
- **商户名称**: 输入商户名称关键词，系统会自动匹配
- **广告账户**: 输入要充值的广告账户名称
- **备注信息**: 输入充值备注（可选）

![创建充值订单](images/create_recharge.png)

#### 3. 确认收款信息

填写完成后，系统会在页面下方显示匹配的收款信息：
- 收款人名称
- 收款账号
- 收款银行（如适用）

#### 4. 提交订单

确认信息无误后，点击"提交订单"按钮。系统会生成唯一的订单号。

### 对私充值流程

#### 1. 完成第三方转账

根据系统显示的收款信息，使用银行APP、支付宝或微信完成转账。

#### 2. 上传付款凭证

1. 点击"上传凭证"按钮
2. 选择付款截图或凭证照片
3. 确保图片清晰，包含完整的转账信息
4. 点击"上传"

![上传凭证](images/upload_voucher.png)

#### 3. 确认付款

上传凭证后，点击"已完成付款"按钮，系统会通知财务人员审核。

### 对公充值流程

#### 1. 银行转账

1. 系统会弹出银行转账页面
2. 按照页面提示完成银行转账
3. 系统会自动接收银行反馈信息

#### 2. 等待确认

财务人员确认收款后，系统会自动完成充值流程。

### 查看充值订单

#### 1. 订单列表

点击"充值管理" → "订单查询"查看所有充值订单。

![订单列表](images/order_list.png)

#### 2. 筛选功能

可以按以下条件筛选订单：
- **时间范围**: 今日、昨日、本周、本月等
- **订单状态**: 待处理、已完成、已退款、已失败
- **商户名称**: 输入商户名称进行搜索
- **付款账号**: 输入付款账号进行搜索

#### 3. 订单详情

点击订单号可以查看详细信息：
- 订单基本信息
- 付款凭证（如有）
- 处理记录
- 状态变更历史

![订单详情](images/order_detail.png)

## 财务审核

> 注意：此功能仅限财务人员使用

### 审核充值订单

#### 1. 进入审核页面

点击"财务审核" → "待审核订单"

#### 2. 查看订单信息

- 核对付款人信息
- 检查付款金额
- 查看付款凭证
- 确认收款情况

![财务审核](images/financial_audit.png)

#### 3. 审核操作

**通过审核**
1. 确认收款无误
2. 点击"通过"按钮
3. 输入审核备注
4. 点击"确认"

**拒绝审核**
1. 发现问题时点击"拒绝"按钮
2. 输入拒绝原因
3. 点击"确认"

### 退款处理

#### 1. 发起退款

1. 在订单详情页面点击"退款"按钮
2. 选择退款原因
3. 输入退款备注
4. 点击"确认退款"

#### 2. 退款流程

- 对私充值：手动原路退回
- 对公充值：系统自动处理退款

## 数据报表

### 交易报表

#### 1. 查看报表

点击"数据报表" → "交易报表"

![交易报表](images/transaction_report.png)

#### 2. 时间筛选

选择查看时间范围：
- **快捷选择**: 今日、昨日、本周、上周、本月、上月
- **自定义**: 选择具体的开始和结束日期

#### 3. 状态筛选

按订单状态筛选：
- 全部
- 充值成功
- 退款
- 失败

#### 4. 其他筛选

- **商户名称**: 按商户筛选
- **付款账号**: 按付款账号筛选
- **收款名称**: 按收款人筛选
- **收款账号**: 按收款账号筛选

### 导出报表

#### 1. 选择导出格式

- Excel格式（.xlsx）
- CSV格式（.csv）

#### 2. 导出操作

1. 设置筛选条件
2. 点击"导出"按钮
3. 选择导出格式
4. 等待文件生成
5. 下载文件

### 报表数据说明

**汇总数据**
- 总交易金额
- 总交易笔数
- 成功金额和笔数
- 失败金额和笔数
- 成功率

**明细数据**
- 订单号
- 付款人
- 付款金额

- 订单状态
- 创建时间
- 完成时间

## 常见问题

### 1. 登录问题

**Q: 忘记密码怎么办？**
A: 请联系系统管理员重置密码。

**Q: 登录后页面空白？**
A: 请检查浏览器版本，建议使用Chrome、Firefox或Edge最新版本。

### 2. 充值问题

**Q: 创建订单后找不到收款信息？**
A: 请检查商户名称是否正确，或联系管理员确认商户配置。

**Q: 上传凭证失败？**
A: 请确保图片格式为JPG、PNG，大小不超过10MB。

**Q: 充值多久能到账？**
A: 对私充值需要财务审核，通常1-2小时内完成；对公充值自动处理，通常几分钟内完成。

### 3. 审核问题

**Q: 审核通过后多久充值到广告账户？**
A: 审核通过后，系统会立即向广告账户系统发送充值请求，通常几分钟内完成。

**Q: 如何处理重复付款？**
A: 发现重复付款时，请及时联系财务人员处理退款。

### 4. 报表问题

**Q: 报表数据不准确？**
A: 请检查筛选条件是否正确，如仍有问题请联系技术支持。

**Q: 导出报表失败？**
A: 可能是数据量过大，请缩小时间范围后重试。

## 系统要求

### 浏览器要求

**推荐浏览器**
- Chrome 90+
- Firefox 88+
- Edge 90+
- Safari 14+

**不支持的浏览器**
- Internet Explorer（所有版本）
- 过旧版本的浏览器

### 网络要求

- 稳定的网络连接
- 建议带宽：1Mbps以上

### 屏幕分辨率

- 最小分辨率：1024x768
- 推荐分辨率：1920x1080

## 安全提醒

### 账户安全

1. **密码安全**
   - 定期修改密码
   - 不要使用简单密码
   - 不要与他人共享密码

2. **登录安全**
   - 使用后及时退出系统
   - 不要在公共电脑上保存密码
   - 发现异常登录及时联系管理员

### 操作安全

1. **充值操作**
   - 仔细核对收款信息
   - 确保付款金额准确
   - 保存好付款凭证

2. **数据安全**
   - 不要泄露订单信息
   - 报表数据仅限内部使用
   - 发现数据异常及时报告
