# CJPayment 系统管理员指南

## 概述

本指南面向CJPayment系统的管理员，详细介绍系统管理、用户管理、商户配置、系统监控等管理功能的使用方法。

## 管理员权限

### 权限级别

系统定义了以下管理员权限级别：

1. **超级管理员**: 拥有所有权限，包括系统配置和用户管理
2. **系统管理员**: 负责用户管理、商户管理、系统配置
3. **财务管理员**: 负责财务审核、报表查看、限额管理
4. **运营管理员**: 负责日常运营、数据分析、客户服务

## 用户管理

### 创建用户

#### 1. 进入用户管理

登录系统后，点击"系统管理" → "用户管理"

![用户管理](images/user_management.png)

#### 2. 添加新用户

1. 点击"添加用户"按钮
2. 填写用户信息：
   - **用户名**: 唯一标识，不可重复
   - **姓名**: 用户真实姓名
   - **邮箱**: 用于接收系统通知
   - **手机号**: 联系方式
   - **部门**: 所属部门
   - **职位**: 工作职位
3. 设置初始密码
4. 分配用户角色
5. 点击"保存"

![添加用户](images/add_user.png)

#### 3. 用户状态管理

- **激活**: 用户可以正常登录使用系统
- **禁用**: 用户无法登录，但数据保留
- **锁定**: 临时锁定，通常因多次登录失败触发

### 角色权限管理

#### 1. 角色管理

**预设角色**
- 财务人员：充值审核、报表查看
- 客服人员：订单查询、客户服务
- 媒介人员：充值创建、订单跟踪
- 运营人员：数据分析、商户管理

**自定义角色**
1. 点击"角色管理"
2. 点击"添加角色"
3. 设置角色名称和描述
4. 配置权限组合
5. 保存角色

![角色管理](images/role_management.png)

#### 2. 权限组管理

**权限组分类**
- 充值管理权限组
- 财务审核权限组
- 商户管理权限组
- 报表查看权限组
- 系统管理权限组

**配置权限组**
1. 选择权限组
2. 勾选具体权限
3. 设置权限范围（全部/部门/个人）
4. 保存配置

## 商户管理

### 商户信息管理

#### 1. 添加商户

1. 进入"商户管理" → "商户列表"
2. 点击"添加商户"
3. 填写商户信息：
   - **商户名称**: 完整的商户名称
   - **商户代码**: 唯一标识码
   - **联系人**: 商户联系人姓名
   - **联系电话**: 联系方式
   - **联系邮箱**: 邮箱地址
   - **业务类型**: 广告投放类型
   - **状态**: 激活/禁用

![添加商户](images/add_merchant.png)

#### 2. 商户限额设置

为每个商户设置交易限额：
- **单笔限额**: 单次充值最大金额
- **单日限额**: 每日充值总额限制
- **单月限额**: 每月充值总额限制

#### 3. 商户状态管理

- **正常**: 可以正常进行充值业务
- **暂停**: 临时停止充值，保留数据
- **禁用**: 永久停用，不可恢复

### 收款账户管理

#### 1. 添加收款账户

1. 进入"收款账户管理"
2. 点击"添加账户"
3. 填写账户信息：
   - **账户名称**: 便于识别的名称
   - **账户类型**: 支付宝/微信/银行卡/其他
   - **账户号码**: 实际账号
   - **账户持有人**: 账户所有者姓名
   - **支付类型**: 对公/对私
   - **银行信息**: 银行名称和支行（银行卡必填）

![添加收款账户](images/add_receive_account.png)

#### 2. 账户限额配置

- **单笔限额**: 单次收款最大金额
- **单日限额**: 每日收款总额限制
- **风险等级**: 高/中/低风险分级

#### 3. 账户状态监控

- **可用余额**: 当日剩余可用额度
- **使用情况**: 当日已使用金额
- **状态**: 正常/维护/禁用

### 轮询规则配置

#### 1. 权重轮询

为商户配置收款账户的权重分配：

1. 选择商户
2. 进入"轮询配置"
3. 设置账户权重：
   - 高权重账户优先使用
   - 权重范围：1-100
   - 支持动态调整

![权重轮询](images/weight_rotation.png)

#### 2. 时间轮询

按时间段分配收款账户：

1. 设置时间段：
   - 上午时段：9:00-12:00
   - 下午时段：13:00-18:00
   - 晚上时段：19:00-23:00
2. 为每个时段分配账户
3. 支持工作日/周末不同配置

#### 3. 金额分层

按充值金额分配账户：

1. 设置金额区间：
   - 小额：0-1000元
   - 中额：1000-5000元
   - 大额：5000元以上
2. 为每个区间分配专用账户
3. 支持风险分散

### 常见故障

#### 1. 系统无法访问

**排查步骤**
1. 检查服务器状态
2. 检查网络连接
3. 检查防火墙设置
4. 检查负载均衡器
5. 查看系统日志

**解决方案**
- 重启相关服务
- 修复网络配置
- 调整防火墙规则
- 切换备用服务器

#### 2. 数据库连接失败

**排查步骤**
1. 检查数据库服务状态
2. 检查连接配置
3. 检查网络连通性
4. 检查用户权限
5. 查看数据库日志

**解决方案**
- 重启数据库服务
- 修复连接配置
- 重置用户密码
- 清理连接池

#### 3. 支付接口异常

**排查步骤**
1. 检查接口配置
2. 测试网络连通性
3. 验证认证信息
4. 检查证书有效性
5. 查看接口日志

**解决方案**
- 更新接口配置
- 重新配置认证
- 更新证书
- 联系服务商
