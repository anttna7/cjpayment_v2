## 系统概述

充值测试系统是一个专为企业客户设计的充值管理平台，支持：
- 多商户管理
- 智能收款账号匹配
- 自动化充值流程
- 实时订单跟踪
- 数据导出和分析

### 系统特点
- **安全可靠**: 采用多层安全防护机制
- **智能匹配**: 自动匹配最优收款账号
- **移动友好**: 支持手机端充值操作
- **实时监控**: 订单状态实时更新
- **数据分析**: 完整的数据统计和导出功能

## 登录和权限

### 登录系统

1. 打开浏览器，访问系统地址
2. 输入用户名和密码
3. 点击"登录"按钮

![登录界面](images/login-screen.png)

### 权限说明

系统采用基于角色的权限控制：

| 角色 | 权限说明 |
|------|----------|
| **超级管理员** | 所有功能权限，包括用户管理 |
| **系统管理员** | 商户管理、账号管理、订单管理 |
| **财务人员** | 订单查看、数据导出 |
| **客服人员** | 订单查看、状态更新 |

### 修改密码

1. 点击右上角用户头像
2. 选择"修改密码"
3. 输入当前密码和新密码
4. 点击"确认修改"

## 商户管理

### 创建商户

1. 进入"商户管理"页面
2. 点击"添加商户"按钮
3. 填写商户信息：
   - **商户名称**: 必填，商户的显示名称
   - **联系人**: 商户联系人姓名
   - **联系电话**: 有效的手机号码
   - **邮箱地址**: 用于接收通知邮件
   - **业务类型**: 选择商户的业务类型
4. 点击"保存"按钮

![创建商户](images/create-merchant.png)

### 编辑商户

1. 在商户列表中找到要编辑的商户
2. 点击"编辑"按钮
3. 修改相关信息
4. 点击"保存"按钮

### 启用/禁用商户

1. 在商户列表中找到目标商户
2. 点击状态切换按钮
3. 确认操作

**注意**: 禁用商户后，该商户的充值链接将无法使用。

### 查看商户详情

1. 点击商户名称或"详情"按钮
2. 查看商户的详细信息和统计数据：
   - 基本信息
   - 绑定的收款账号
   - 充值订单统计
   - 充值链接信息

## 收款账号管理

### 绑定收款账号

1. 进入"收款账号管理"页面
2. 选择要绑定账号的商户
3. 点击"绑定账号"按钮
4. 从可用账号列表中选择账号
5. 设置账号优先级（数字越小优先级越高）
6. 点击"确认绑定"

![绑定账号](images/bind-account.png)

### 调整账号优先级

1. 在已绑定账号列表中找到目标账号
2. 点击"调整优先级"按钮
3. 输入新的优先级数值
4. 点击"确认"

### 解绑收款账号

1. 在已绑定账号列表中找到要解绑的账号
2. 点击"解绑"按钮
3. 确认解绑操作

**警告**: 解绑账号可能影响正在进行的充值订单。

### 查看账号使用情况

1. 点击账号名称查看详情
2. 查看账号的使用统计：
   - 今日收款金额
   - 剩余限额
   - 使用次数
   - 成功率统计

## 充值链接管理

### 生成充值链接

1. 进入"充值链接管理"页面
2. 选择商户
3. 点击"生成链接"按钮
4. 配置链接参数：
   - **页面标题**: 充值页面显示的标题
   - **有效期**: 链接的有效时间
   - **单次限额**: 单笔充值的最大金额
   - **日限额**: 每日充值总限额
5. 点击"生成"按钮

![生成链接](images/generate-link.png)

### 管理充值链接

1. 在链接列表中查看所有生成的链接
2. 可以进行以下操作：
   - **复制链接**: 复制链接地址
   - **生成二维码**: 生成二维码供扫描使用
   - **启用/禁用**: 控制链接的可用状态
   - **查看统计**: 查看链接的使用统计

### 链接配置说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 页面标题 | 充值页面显示的标题 | 商户名称 + "充值" |
| 有效期 | 链接的有效时间 | 永久有效 |
| 单次限额 | 单笔充值最大金额 | 50,000元 |
| 日限额 | 每日充值总限额 | 500,000元 |

## 订单管理

### 查看订单列表

1. 进入"订单管理"页面
2. 使用筛选条件查找订单：
   - **日期范围**: 选择订单创建日期
   - **商户**: 筛选特定商户的订单
   - **状态**: 按订单状态筛选
   - **金额范围**: 按充值金额筛选
3. 点击"查询"按钮

![订单列表](images/order-list.png)

### 订单状态说明

| 状态 | 说明 | 操作 |
|------|------|------|
| **待付款** | 订单已创建，等待付款 | 可取消订单 |
| **已付款** | 用户已上传付款凭证 | 需要审核凭证 |
| **已确认** | 付款凭证审核通过 | 可标记为完成 |
| **已完成** | 充值流程完成 | 无需操作 |
| **已取消** | 订单已取消 | 无需操作 |

### 处理订单

#### 审核付款凭证
1. 点击订单号进入详情页面
2. 查看用户上传的付款凭证
3. 核对付款信息：
   - 付款金额是否正确
   - 付款账户是否匹配
   - 付款时间是否合理
4. 选择审核结果：
   - **通过**: 确认付款有效
   - **拒绝**: 付款信息有误
5. 填写审核备注
6. 点击"提交审核"

![审核凭证](images/review-proof.png)

#### 更新订单状态
1. 在订单详情页面
2. 选择新的订单状态
3. 填写状态更新说明
4. 点击"更新状态"

### 订单详情信息

订单详情页面包含以下信息：
- **基本信息**: 订单号、创建时间、商户信息
- **付款信息**: 付款人姓名、金额、广告账户
- **收款信息**: 匹配的收款账号、账号信息
- **状态历史**: 订单状态变更记录
- **操作日志**: 所有操作的详细记录

## 数据导出

### 导出订单数据

1. 进入"数据导出"页面
2. 选择导出条件：
   - **日期范围**: 选择要导出的日期范围
   - **商户**: 选择特定商户或全部
   - **订单状态**: 选择要导出的订单状态
   - **数据格式**: Excel 或 CSV 格式
3. 点击"导出数据"按钮
4. 等待文件生成完成
5. 点击"下载"按钮获取文件

![数据导出](images/data-export.png)

### 导出内容说明

导出的 Excel 文件包含以下字段：
- 订单号
- 创建时间
- 商户名称
- 付款人姓名
- 充值金额
- 广告账户
- 付款类型
- 收款账号
- 订单状态
- 完成时间

### 定时导出设置

1. 在数据导出页面点击"定时导出设置"
2. 配置定时任务：
   - **执行时间**: 每日执行的时间
   - **导出范围**: 前一天或当天数据
   - **接收邮箱**: 导出文件发送的邮箱地址
3. 点击"保存设置"

## 充值流程

### 付款人充值操作

#### 1. 访问充值链接
- 通过管理员提供的链接或二维码访问充值页面
- 系统会显示商户信息和充值说明

#### 2. 填写充值信息
- **付款人姓名**: 填写真实姓名
- **充值金额**: 输入要充值的金额
- **广告账户**: 填写要充值的广告账户ID
- **付款类型**: 选择对公或对私付款

![充值表单](images/recharge-form.png)

#### 3. 获取收款信息
- 点击"提交申请"按钮
- 系统自动匹配最优收款账号
- 显示收款账号信息和付款指引

#### 4. 完成付款
- 按照页面显示的收款信息进行转账
- 保存付款凭证（截图或照片）

#### 5. 上传付款凭证
- 点击"上传凭证"按钮
- 选择付款凭证文件
- 填写付款说明
- 点击"提交凭证"

#### 6. 等待审核
- 系统会通知管理员审核付款凭证
- 付款人可以通过订单号查询审核进度

### 移动端充值

移动端充值流程与桌面端基本相同，但针对手机操作进行了优化：
- 表单输入更加便捷
- 支持拍照上传付款凭证
- 一键复制收款信息
- 支持微信/支付宝等移动支付

## 常见问题

### Q1: 忘记登录密码怎么办？
**A**: 请联系系统管理员重置密码，或使用"忘记密码"功能通过邮箱重置。

### Q2: 为什么无法绑定收款账号？
**A**: 可能的原因：
- 账号已被其他商户绑定
- 账号状态异常
- 权限不足
请检查账号状态或联系管理员。

### Q3: 充值链接无法访问怎么办？
**A**: 检查以下几点：
- 链接是否已过期
- 商户状态是否正常
- 链接是否被禁用
如问题持续，请联系技术支持。

### Q4: 订单状态长时间不更新？
**A**: 可能的原因：
- 付款凭证待审核
- 系统处理延迟
- 网络连接问题
建议刷新页面或联系客服。

### Q5: 导出的数据不完整？
**A**: 请检查：
- 筛选条件是否正确
- 日期范围是否合适
- 是否有权限查看所有数据

### Q6: 如何提高账号匹配成功率？
**A**: 建议：
- 为商户绑定多个收款账号
- 合理设置账号优先级
- 定期检查账号限额和状态
- 及时处理异常账号

### Q7: 移动端充值页面显示异常？
**A**: 尝试以下解决方案：
- 刷新页面
- 清除浏览器缓存
- 使用其他浏览器
- 检查网络连接

### Q8: 如何批量处理订单？
**A**: 目前系统支持：
- 批量导出订单数据
- 批量更新订单状态（开发中）
- 批量发送通知（开发中）
