# CJPayment 充值系统架构设计

## 系统概述

现金充值-账户币加值系统，支持用户通过现金充值获得账户币，包含完整的支付、审核、加值、通知流程。

## 业务流程图

```
用户充值流程:
[用户点击充值链接] → [现金付款页面] → [填写付款信息] → [选择充值账户] → [选择对公/对私] 
    ↓
[对公自动跳转网关] OR [对私手动转账+上传凭证] → [系统收到通知] → [财务审核确认] 
    ↓
[现金充值成功] → [账户币加值] → [机器人通知] → [完成]
```

## 核心模块

### 1. 充值前端模块 (Recharge Frontend)
- 通用/专用充值链接处理
- 账户信息搜索匹配
- 支付方式选择
- 凭证上传

### 2. 账户管理模块 (Account Management)
- 商户信息管理
- 收款账户管理
- 返点政策设置
- 账户状态控制

### 3. 订单处理模块 (Order Processing)
- 订单生成与管理
- 支付状态跟踪
- 轮询规则执行

### 4. 财务审核模块 (Finance Audit)
- 到账确认
- 凭证审核
- 异常处理

### 5. 账户币系统 (Account Currency)
- 加值计算
- 余额管理
- 返点政策执行

### 6. 通知系统 (Notification Bot)
- 飞书群通知
- 企业微信通知
- 状态更新

## 数据流向

```
充值请求 → 订单创建 → 支付处理 → 财务审核 → 账户加值 → 机器人通知
```

## 技术栈

- **前端**: HTML5 + JavaScript ES6+ + CSS3
- **后端**: Go + Gin Framework
- **数据库**: MySQL 8.0
- **消息队列**: Redis
- **文件存储**: 本地存储 + 云存储备份
- **通知**: 飞书OpenAPI + 企业微信API

## 安全特性

- 订单号唯一性保证
- 凭证图片水印验证
- 多重财务审核机制
- 账户余额异常监控
- 操作日志完整记录
