## 登录和账户问题

### Q1: 忘记登录密码怎么办？

**A:** 
1. 联系系统管理员重置密码
2. 管理员会为您生成临时密码
3. 首次登录后请立即修改密码
4. 新密码需符合安全要求：至少8位，包含大小写字母、数字和特殊字符

### Q2: 登录时提示"用户名或密码错误"？

**A:** 
1. 检查用户名和密码是否正确输入
2. 注意大小写敏感
3. 确认账户未被禁用或锁定
4. 如果多次输入错误，账户可能被临时锁定，请等待30分钟后重试
5. 仍无法解决请联系管理员

### Q3: 登录后页面显示空白或加载不完整？

**A:** 
1. **浏览器兼容性**：
   - 推荐使用Chrome 90+、Firefox 88+、Edge 90+
   - 不支持IE浏览器
2. **清除浏览器缓存**：
   - Chrome: Ctrl+Shift+Delete
   - Firefox: Ctrl+Shift+Delete
   - Edge: Ctrl+Shift+Delete
3. **检查网络连接**：确保网络稳定
4. **禁用浏览器插件**：某些插件可能影响页面加载
5. **尝试无痕模式**：排除扩展程序干扰

### Q4: 如何修改个人密码？

**A:** 
1. 登录系统后，点击右上角用户名
2. 选择"个人中心"
3. 点击"修改密码"
4. 输入当前密码和新密码
5. 确认新密码并保存
6. 密码要求：至少8位，包含大小写字母、数字和特殊字符

### Q5: 账户被锁定怎么办？

**A:** 
账户锁定通常由以下原因造成：
1. **连续登录失败**：等待30分钟自动解锁，或联系管理员
2. **异常登录行为**：联系管理员确认身份后解锁
3. **管理员手动锁定**：联系管理员了解锁定原因

## 充值操作问题

### Q6: 创建充值订单时找不到商户信息？

**A:** 
1. **检查商户名称**：
   - 确保输入的商户名称正确
   - 支持模糊搜索，输入关键词即可
   - 商户名称区分大小写
2. **商户状态检查**：
   - 商户可能被暂停或禁用
   - 联系管理员确认商户状态
3. **权限问题**：
   - 确认您有权限为该商户创建充值订单
   - 联系管理员检查权限配置

### Q7: 充值金额有什么限制？

**A:** 
充值金额限制分为多个层级：
1. **系统限制**：
   - 最小金额：1元
   - 最大金额：根据系统配置
2. **商户限制**：
   - 单笔限额：由管理员设置
   - 单日限额：累计当日充值金额
3. **收款账户限制**：
   - 账户单笔限额
   - 账户单日限额
4. **用户权限限制**：
   - 根据用户角色设定的限额

### Q8: 上传付款凭证失败怎么办？

**A:** 
1. **文件格式要求**：
   - 支持格式：JPG、JPEG、PNG、PDF
   - 不支持：GIF、BMP、TIFF等格式
2. **文件大小限制**：
   - 最大文件大小：10MB
   - 建议大小：2MB以内
3. **图片质量要求**：
   - 图片清晰，信息完整
   - 包含完整的转账信息
   - 避免模糊、截断的图片
4. **网络问题**：
   - 检查网络连接稳定性
   - 尝试刷新页面重新上传
   - 使用有线网络或稳定的WiFi

### Q9: 充值订单创建后多久需要完成付款？

**A:** 
1. **对私充值**：
   - 订单有效期：2小时
   - 超时后订单自动取消
   - 可以重新创建订单
2. **对公充值**：
   - 订单有效期：24小时
   - 银行转账通常需要更长时间
   - 超时可联系财务延期处理

### Q10: 为什么充值订单状态一直是"待处理"？

**A:** 
订单状态"待处理"的可能原因：
1. **对私充值**：
   - 等待上传付款凭证
   - 等待财务人员审核
   - 审核通常在1-2小时内完成
2. **对公充值**：
   - 等待银行转账到账
   - 等待银行系统反馈
   - 等待财务确认
3. **系统问题**：
   - 外部接口异常
   - 网络连接问题
   - 联系技术支持处理

## 财务审核问题

### Q11: 财务审核需要多长时间？

**A:** 
1. **正常工作时间**：
   - 工作日：1-2小时内完成
   - 周末和节假日：可能延迟到下个工作日
2. **特殊情况**：
   - 大额充值：可能需要额外审核时间
   - 信息不清晰：需要补充材料
   - 异常订单：需要详细核实
3. **加急处理**：
   - 紧急订单可联系财务人员
   - 提供详细说明和证明材料

### Q12: 财务审核被拒绝怎么办？

**A:** 
审核被拒绝的常见原因和解决方案：
1. **付款信息不符**：
   - 付款人姓名与订单不符
   - 付款金额与订单不符
   - 重新核对信息后创建新订单
2. **凭证不清晰**：
   - 重新上传清晰的付款凭证
   - 确保包含完整的转账信息
3. **重复付款**：
   - 联系财务人员处理退款
   - 避免重复创建订单
4. **账户异常**：
   - 收款账户可能存在问题
   - 联系管理员检查账户状态

### Q13: 如何申请退款？

**A:** 
退款申请流程：
1. **联系财务人员**：
   - 说明退款原因
   - 提供订单号和相关证明
2. **填写退款申请**：
   - 退款金额
   - 退款原因
   - 退款账户信息
3. **等待审批**：
   - 财务审核退款申请
   - 通常1-3个工作日完成
4. **退款到账**：
   - 对私充值：原路退回
   - 对公充值：银行转账退回
   - 到账时间：1-5个工作日

## 商户管理问题

### Q14: 如何添加新商户？

**A:** 
添加新商户需要管理员权限：
1. **收集商户信息**：
   - 商户全称
   - 联系人信息
   - 业务类型
   - 广告账户信息
2. **配置收款账户**：
   - 绑定收款账户
   - 设置轮询规则
   - 配置限额参数
3. **测试验证**：
   - 创建测试订单
   - 验证充值流程
   - 确认系统对接正常

### Q15: 商户收款账户如何轮询？

**A:** 
系统支持多种轮询策略：
1. **权重轮询**：
   - 根据账户权重分配
   - 权重高的账户优先使用
   - 支持动态调整权重
2. **时间轮询**：
   - 按时间段分配账户
   - 不同时段使用不同账户
   - 支持工作日/周末配置
3. **金额分层**：
   - 按充值金额分配账户
   - 小额、中额、大额使用不同账户
   - 有效分散风险

### Q16: 商户限额如何设置？

**A:** 
商户限额设置包括：
1. **单笔限额**：
   - 单次充值最大金额
   - 防止异常大额交易
2. **单日限额**：
   - 每日充值总额限制
   - 每日0点自动重置
3. **单月限额**：
   - 每月充值总额限制
   - 每月1号自动重置
4. **动态调整**：
   - 根据业务需要调整
   - 需要管理员权限
   - 调整记录可追溯

## 报表和数据问题

### Q17: 报表数据不准确怎么办？

**A:** 
数据不准确的排查步骤：
1. **检查筛选条件**：
   - 确认时间范围设置正确
   - 检查状态筛选条件
   - 验证其他筛选参数
2. **数据同步延迟**：
   - 报表数据可能有5-10分钟延迟
   - 等待数据同步完成
3. **权限限制**：
   - 确认您有权限查看相关数据
   - 不同角色看到的数据范围不同
4. **联系技术支持**：
   - 提供具体的数据差异
   - 说明预期结果和实际结果

### Q18: 如何导出报表数据？

**A:** 
报表导出步骤：
1. **设置筛选条件**：
   - 选择时间范围
   - 设置其他筛选条件
2. **选择导出格式**：
   - Excel格式（.xlsx）：适合数据分析
   - CSV格式（.csv）：适合系统导入
3. **执行导出**：
   - 点击"导出"按钮
   - 选择导出格式
   - 等待文件生成
4. **下载文件**：
   - 文件生成后自动下载
   - 大数据量可能需要等待几分钟

### Q19: 导出报表失败怎么办？

**A:** 
导出失败的解决方案：
1. **数据量过大**：
   - 缩小时间范围
   - 增加筛选条件
   - 分批导出数据
2. **网络问题**：
   - 检查网络连接稳定性
   - 尝试刷新页面重新导出
3. **浏览器问题**：
   - 检查浏览器下载设置
   - 清除浏览器缓存
   - 尝试其他浏览器
4. **权限问题**：
   - 确认有导出权限
   - 联系管理员检查权限配置

### Q20: 报表中的状态含义是什么？

**A:** 
订单状态说明：
1. **待处理 (Pending)**：
   - 订单已创建，等待付款或审核
2. **处理中 (Processing)**：
   - 正在处理付款或审核中
3. **已完成 (Completed)**：
   - 充值成功，资金已到账
4. **已退款 (Refunded)**：
   - 订单已退款，资金已退回
5. **已失败 (Failed)**：
   - 充值失败，需要重新处理
6. **已取消 (Cancelled)**：
   - 订单被取消，未进行充值

   - 提供详细的错误信息

## 安全和权限问题

### Q24: 如何确保账户安全？

**A:** 
账户安全最佳实践：
1. **密码安全**：
   - 使用强密码
   - 定期更换密码
   - 不要与他人共享密码
2. **登录安全**：
   - 及时退出系统
   - 不在公共电脑保存密码
   - 注意异常登录提醒
3. **操作安全**：
   - 仔细核对操作信息
   - 不要泄露敏感数据
   - 发现异常及时报告

### Q25: 没有权限访问某个功能？

**A:** 
权限问题解决方案：
1. **确认权限需求**：
   - 了解功能所需权限
   - 确认自己的角色权限
2. **联系管理员**：
   - 说明业务需求
   - 申请相应权限
   - 等待权限分配
3. **临时解决方案**：
   - 请有权限的同事代为操作
   - 使用其他替代功能

### Q26: 发现可疑的系统活动怎么办？

**A:** 
发现可疑活动的处理步骤：
1. **立即报告**：
   - 联系系统管理员
   - 详细描述可疑活动
   - 提供相关证据
2. **保护账户**：
   - 立即修改密码
   - 检查账户操作记录
   - 暂停敏感操作
3. **配合调查**：
   - 提供详细信息
   - 配合安全检查
   - 遵循安全建议

## 移动端使用问题

### Q27: 手机上可以使用系统吗？

**A:** 
移动端使用说明：
1. **浏览器支持**：
   - 支持手机浏览器访问
   - 推荐使用Chrome、Safari
   - 响应式设计，自适应屏幕
2. **功能限制**：
   - 部分复杂功能建议在电脑上操作
   - 文件上传功能可能受限
   - 报表导出建议在电脑上进行
3. **操作建议**：
   - 使用横屏模式获得更好体验
   - 确保网络连接稳定
   - 定期清理浏览器缓存

### Q28: 手机上传图片失败？

**A:** 
手机上传图片的解决方案：
1. **权限设置**：
   - 允许浏览器访问相机和相册
   - 检查应用权限设置
2. **图片要求**：
   - 确保图片清晰
   - 控制图片大小
   - 使用支持的格式
3. **网络问题**：
   - 使用稳定的WiFi网络
   - 避免使用移动数据上传大文件
