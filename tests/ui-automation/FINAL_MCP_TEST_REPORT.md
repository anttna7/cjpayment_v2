#### 1. **模态框选择器一致性**
```javascript

page.waitForSelector('.modal, .modal-dialog', { timeout: 5000 })

// 解决方案: 使用多重选择器
const modalSelectors = [
  '.modal:visible',
  '[role="dialog"]:visible', 
  '.modal-dialog:visible'
];
```

#### 2. **严格模式冲突**

